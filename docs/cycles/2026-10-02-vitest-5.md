# Vitest 5 major (CI on Node 24)

## Context

This is the one dependabot **major** left after the 2026-10-02 minor and patch drain (#598, `docs/cycles/2026-10-02-deps-batch.md`). CLAUDE.md § Dependency cadence gives each major its own cycle.

Two open PRs cover it:
- **#527** is a prepared migration (`docs/cycles/2026-09-25-pr-527-vitest-v5.md`), now 24+ commits behind `staging`.
- **#588** is dependabot's coverage-only bump.

Neither can merge alone, because `@vitest/coverage-v8` peers `vitest` at an exact version. Vitest 5 also needs Node `^22.12 || ^24 || >=26`, and CI runs Node 20.

This cycle ports #527's proven changes onto current `staging` at the latest patch (5.0.3). The Vercel project already runs **Node 24.x**, so moving CI to 24 also makes CI test on the production runtime. #527 and #588 are then closed as superseded.
