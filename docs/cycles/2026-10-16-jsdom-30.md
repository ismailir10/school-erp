# jsdom 29 → 30 (2026-10-16)

## Context

Dependabot PR #646 bumps `jsdom` (dev only: the Vitest `jsdom` project for `*.test.tsx` and the suites named in `DOM_TS_SUITES`) from 29.1.1 to 30.1.2. Its CI was green on a staging five commits old. It is the second step of the branch consolidation in `2026-10-16-branch-consolidation.md`; majors go one per cycle (CLAUDE.md § Dependency cadence), so it gets its own PR.

## Decisions

- Take it. The 30.x notes are performance work and correctness fixes (focus, `getComputedStyle()` invalidation, selector matching, CSS custom properties). The breaking change in 30.0 (`querySelectorAll` matching the element itself) was reverted in 30.1.0. No production code runs jsdom.
- npm resolves `^30.1.2` to 30.1.3 (a later patch).
